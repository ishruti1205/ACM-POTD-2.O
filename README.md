# ACM IGDTUW – POTD 2.O Challenge (Competitive Programming)

This repository contains my solutions for the **ACM IGDTUW Problem of the Day (POTD) 2.O Challenge** conducted from **1 October 2026 to 1 December 2026**.

The challenge requires participants to solve **one coding problem every day** and upload proof of the accepted solution on GitHub. Participants who solve **at least 52 out of 62 problems** will receive a certificate of appreciation.

## 📂 Repository Structure

Each day’s solution is uploaded as a Markdown file following the format: `Fullname_Date_POTD-Day.md`

Example: `Shruti_01-10-2026_Day-01.md`

Each file contains:
* Problem Statement
* Approach
* Code
* Screenshot of Accepted Submission

All solutions are uploaded in the form of **Markdown (.md) files** as required by the event guidelines.
